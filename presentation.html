O Jogo Isolation

Isolation é um jogo de dois jogadores em um tabuleiro 7 × 7. Cada turno tem duas fases: mover o peão para uma célula válida e depois bloquear permanentemente qualquer célula livre do tabuleiro. Quem ficar sem movimentos disponíveis perde.

🎯
Objetivo

Forçar o oponente a ficar sem movimentos bloqueando o tabuleiro estrategicamente.

♟️
Movimento

Cada peão se move como um rei do xadrez — uma casa em qualquer das 8 direções (horizontal, vertical ou diagonal).

🚫
Bloqueio

Após mover, o jogador bloqueia qualquer célula livre. Células bloqueadas são permanentes.

8 destinos possíveis (ignorando bordas e bloqueios)

O peão se move como um rei do xadrez: uma casa em qualquer das 8 direções — horizontal, vertical ou diagonal. Células bloqueadas nas adjacências simplesmente não são destinos válidos.

# 8 direções do movimento de rei (1 casa em cada direção) DIRECOES_REI = [ (-1,-1), (-1, 0), (-1,+1), # cima-esq, cima, cima-dir ( 0,-1), ( 0,+1), # esquerda, direita (+1,-1), (+1, 0), (+1,+1), # baixo-esq, baixo, baixo-dir ]
Diferença do xadrez: no Isolation o rei não pode pular células. Se uma célula adjacente está bloqueada, simplesmente não é um destino válido.

class IsolationState: """Estado imutável do jogo Isolation — nunca modificado após criado""" def __init__(self): # Tabuleiro 7×7: True = livre | False = bloqueado permanentemente self.tabuleiro = [[True] * 7 for _ in range(7)] self.posicao_jogador1 = None # (linha, coluna) self.posicao_jogador2 = None self.jogador_ativo = 1 # quem deve jogar agora: 1 ou 2 def aplicar_acao(self, acao): """Retorna NOVO estado sem modificar o atual""" destino_do_peao, celula_a_bloquear = acao novo_estado = self._copiar() if self.jogador_ativo == 1: novo_estado.posicao_jogador1 = destino_do_peao else: novo_estado.posicao_jogador2 = destino_do_peao linha_bl, col_bl = celula_a_bloquear novo_estado.tabuleiro[linha_bl][col_bl] = False # bloqueia permanentemente novo_estado.jogador_ativo = 3 - self.jogador_ativo # alterna: 1→2→1→... return novo_estado def jogo_terminou(self): """Verdadeiro se o jogador ativo não tem nenhum movimento disponível""" return len(self.get_acoes_legais()) == 0

Espaço de Ações

Uma ação em Isolation é sempre um par (mover_para, bloquear). O espaço de ações cresce com o número de células livres — criando uma explosão combinatória que torna a busca exaustiva inviável.

def get_acoes_legais(self, jogador=None): """Gera todos os pares (destino_do_peao, celula_a_bloquear)""" if jogador is None: jogador = self.jogador_ativo posicao_atual = (self.posicao_jogador1 if jogador == 1 else self.posicao_jogador2) # Passo 1: destinos do rei (1 casa em qualquer das 8 direções) destinos_validos = [] for delta_linha, delta_col in DIRECOES_REI: nova_linha = posicao_atual[0] + delta_linha nova_col = posicao_atual[1] + delta_col if 0 <= nova_linha < 7 and 0 <= nova_col < 7: if self.tabuleiro[nova_linha][nova_col]: # célula livre? destinos_validos.append((nova_linha, nova_col)) # Passo 2: combinar cada destino com qualquer célula livre para bloquear celulas_livres = [(linha, col) for linha in range(7) for col in range(7) if self.tabuleiro[linha][col]] return [(destino, bloquear) for destino in destinos_validos for bloquear in celulas_livres if bloquear != destino] # não pode bloquear onde acabou de ir

Algoritmo Minimax

O Minimax modela o jogo como uma busca em árvore adversarial. A IA (MAX) tenta maximizar o valor da posição; o oponente (MIN) tenta minimizar. Os valores sobem recursivamente das folhas até a raiz.

MAX: valor = max(filhos)  |  MIN: valor = min(filhos)
Raiz
Nó MAX — a IA escolhe a ação com maior valor retornado.
Folha
Profundidade 0 ou estado terminal → heuristic(estado).
Backprop
Valores sobem das folhas à raiz alternando MAX e MIN.
Exemplo — árvore de profundidade 2

■ Nó MAX  |  ■ Nó MIN  |  ■ Folha  |  ― Caminho escolhido · MIN(3,7,4)=3 · MIN(5,9,2)=2 · MAX(3,2)=3 → ramo esquerdo

class MinimaxAgent: """Agente que usa Minimax para busca adversarial""" def __init__(self, profundidade_maxima=3): self.profundidade_maxima = profundidade_maxima self.INFINITO = float('inf') def escolher_acao(self, estado_atual): """Retorna a melhor ação para o jogador ativo""" melhor_acao = None melhor_pontuacao = -self.INFINITO for acao in estado_atual.get_acoes_legais(): proximo_estado = estado_atual.aplicar_acao(acao) pontuacao = self._minimax(proximo_estado, self.profundidade_maxima - 1, jogador_esta_maximizando=False) if pontuacao > melhor_pontuacao: melhor_pontuacao = pontuacao melhor_acao = acao return melhor_acao def _minimax(self, estado, profundidade, jogador_esta_maximizando): """Busca Minimax recursiva""" # Caso base: profundidade esgotada ou jogo acabou if profundidade == 0 or estado.jogo_terminou(): return self.avaliar(estado) acoes_possiveis = estado.get_acoes_legais() if jogador_esta_maximizando: # Nó MAX: quer o maior valor possível melhor_valor = -self.INFINITO for acao in acoes_possiveis: estado_filho = estado.aplicar_acao(acao) pontuacao_filho = self._minimax(estado_filho, profundidade-1, False) melhor_valor = max(melhor_valor, pontuacao_filho) return melhor_valor else: # Nó MIN: quer o menor valor possível melhor_valor = self.INFINITO for acao in acoes_possiveis: estado_filho = estado.aplicar_acao(acao) pontuacao_filho = self._minimax(estado_filho, profundidade-1, True) melhor_valor = min(melhor_valor, pontuacao_filho) return melhor_valor
Limitação: sem otimização, o Minimax explora todos os ramos. Para d=5 com branching factor 30: 305 ≈ 24 milhões de nós — inviável nos 150ms disponíveis.

Poda Alfa-Beta

A Poda Alfa-Beta elimina ramos da árvore que garantidamente não influenciam a decisão final. Ela mantém dois valores durante a busca: alpha (melhor garantido para MAX) e beta (melhor garantido para MIN). Quando beta ≤ alpha, o ramo pode ser ignorado com segurança.

β ≤ α → poda (break)
α (alpha)
Melhor valor que MAX já garantiu em outro ramo. MIN nunca deixará abaixo disso.
β (beta)
Melhor valor que MIN já garantiu. MAX nunca conseguirá acima disso neste ramo.
Resultado
Complexidade cai de O(bd) para O(bd/2) — equivale a dobrar a profundidade.
Exemplo — poda em ação: nó n23 é cortado

Após n1=2, root tem α=2. No ramo n2: ao encontrar valor 1, β=1 ≤ α=2 → ✗ n23 podado sem avaliar

class AlphaBetaAgent: """Minimax com Poda Alfa-Beta — O(b^(d/2))""" def escolher_acao(self, estado_atual): melhor_acao = None alfa = -float('inf') # melhor pontuação garantida para MAX até agora beta = float('inf') # melhor pontuação garantida para MIN até agora for acao in estado_atual.get_acoes_legais(): proximo_estado = estado_atual.aplicar_acao(acao) pontuacao = self._alfa_beta(proximo_estado, self.profundidade_maxima - 1, alfa, beta, jogador_e_max=False) if pontuacao > alfa: alfa = pontuacao melhor_acao = acao return melhor_acao def _alfa_beta(self, estado, profundidade, alfa, beta, jogador_e_max): if profundidade == 0 or estado.jogo_terminou(): return self.avaliar(estado) if jogador_e_max: melhor_valor = -float('inf') for acao in estado.get_acoes_legais(): estado_filho = estado.aplicar_acao(acao) melhor_valor = max(melhor_valor, self._alfa_beta(estado_filho, profundidade-1, alfa, beta, False)) alfa = max(alfa, melhor_valor) if beta <= alfa: break # MIN nunca escolherá este ramo → Poda Beta! return melhor_valor else: melhor_valor = float('inf') for acao in estado.get_acoes_legais(): estado_filho = estado.aplicar_acao(acao) melhor_valor = min(melhor_valor, self._alfa_beta(estado_filho, profundidade-1, alfa, beta, True)) beta = min(beta, melhor_valor) if beta <= alfa: break # MAX nunca escolherá este ramo → Poda Alpha! return melhor_valor
Resultado garantido: a Poda Alfa-Beta sempre retorna a mesma decisão que o Minimax puro — nunca piora a jogada, apenas economiza tempo eliminando ramos irrelevantes.

Função Heurística

Nas folhas da árvore (profundidade limite), em vez de jogar até o fim, chamamos uma função heurística que estima a qualidade da posição. A heurística combina cinco componentes ponderados.

score = w₁·mob + w₂·opp + w₃·ter + w₄·ctr + w₅·iso

A distância de Chebyshev calcula o mínimo de passos que um rei precisa para ir de um ponto a outro. É o máximo entre as diferenças de linha e coluna — muito mais adequada ao movimento do rei do que a distância de Manhattan.

d = max( |Δlinha|, |Δcoluna| )

Exemplo: de (1,1) até (4,5) →
max( |4−1|, |5−1| ) = max(3, 4) = 4 passos

Usos na heurística: (1) centralidade — distância de Chebyshev do peão ao centro do tabuleiro; (2) isolamento — distância de Chebyshev entre os dois jogadores (quanto maior, mais isolado o oponente).
class HeuristicAgent: PESOS = { 'mobilidade': 2.5, # meus movimentos disponíveis menos os do oponente 'territorio': 1.2, # células que consigo alcançar vs células do oponente 'centralidade': 0.8, # quão central estou (Chebyshev ao centro) 'isolamento': 1.5, # distância de Chebyshev entre os dois jogadores } def avaliar(self, estado): """Retorna pontuação — quanto maior, melhor para o jogador ativo""" eu = estado.jogador_ativo oponente = estado.jogador_inativo # Verificar estados terminais (vitória / derrota imediata) movimentos_proprios = len(estado.get_acoes_legais(eu)) movimentos_oponente = len(estado.get_acoes_legais(oponente)) if movimentos_proprios == 0: return float('-inf') # derrota if movimentos_oponente == 0: return float('+inf') # vitória # Componente 1: diferença de mobilidade (meus mvs − mvs do oponente) diferenca_mobilidade = movimentos_proprios - movimentos_oponente # Componente 2: diferença de território (flood fill) territorio_proprio = self._flood_fill(estado, eu) territorio_oponente = self._flood_fill(estado, oponente) diferenca_territorio = territorio_proprio - territorio_oponente # Componente 3: centralidade via Chebyshev (mais perto do centro = melhor) centro_linha, centro_col = estado.tamanho // 2, estado.tamanho // 2 minha_linha, minha_col = estado.get_posicao(eu) distancia_ao_centro = self.chebyshev( (minha_linha, minha_col), (centro_linha, centro_col) ) bonus_centralidade = -distancia_ao_centro # negativo: perto = bom # Componente 4: isolamento via Chebyshev (distância entre os dois jogadores) minha_posicao = estado.get_posicao(eu) posicao_oponente = estado.get_posicao(oponente) isolamento_oponente = self.chebyshev(minha_posicao, posicao_oponente) return ( self.PESOS['mobilidade'] * diferenca_mobilidade + self.PESOS['territorio'] * diferenca_territorio + self.PESOS['centralidade'] * bonus_centralidade + self.PESOS['isolamento'] * isolamento_oponente ) def chebyshev(self, posicaoA, posicaoB): """Distância de Chebyshev = mínimo de passos do rei entre dois pontos""" diferenca_linhas = abs(posicaoA[0] - posicaoB[0]) diferenca_colunas = abs(posicaoA[1] - posicaoB[1]) return max(diferenca_linhas, diferenca_colunas) def _flood_fill(self, estado, jogador): """Conta células que o jogador consegue alcançar (BFS com movimentos de rei)""" posicao_inicial = estado.get_posicao(jogador) celulas_visitadas = {posicao_inicial} celulas_para_explorar = [posicao_inicial] while celulas_para_explorar: linha_atual, col_atual = celulas_para_explorar.pop() for delta_linha, delta_col in DIRECOES_REI: nova_linha = linha_atual + delta_linha nova_col = col_atual + delta_col nova_pos = (nova_linha, nova_col) if nova_pos not in celulas_visitadas: if estado.posicao_valida(nova_pos): # dentro do tabuleiro e livre? celulas_visitadas.add(nova_pos) celulas_para_explorar.append(nova_pos) return len(celulas_visitadas) # total de células alcançáveis

Aprofundamento Iterativo

O Aprofundamento Iterativo (IDDFS) executa a busca Alfa-Beta em profundidades crescentes — d=1, d=2, d=3, ... — até o tempo limite ser atingido. Ao terminar o tempo, retorna o melhor resultado encontrado na última profundidade completa.

✓
Segurança

Sempre tem uma resposta válida — a da profundidade anterior — independente do timeout.

∞
Adaptável

Aproveita ao máximo o tempo disponível, indo tão fundo quanto possível.

O(d)
Memória

Usa apenas espaço linear — cada busca de profundidade descarta os nós anteriores.

import time class IterativeDeepeningAgent: """Alpha-Beta com Aprofundamento Iterativo e controle de tempo""" def __init__(self, limite_tempo_ms=150): self.limite_tempo = limite_tempo_ms # tempo máximo em milissegundos def escolher_acao(self, estado_atual): """Retorna a melhor ação encontrada antes do tempo esgotar""" tempo_inicio = time.time() melhor_movimento = estado_atual.get_acoes_legais()[0] # fallback seguro profundidade_atual = 1 # começa raso e vai aprofundando try: while True: tempo_decorrido = (time.time() - tempo_inicio) * 1000 if tempo_decorrido >= self.limite_tempo: break # tempo esgotado: retorna o que já tem movimento_encontrado = self._buscar_profundidade( estado_atual, profundidade_atual, tempo_inicio ) melhor_movimento = movimento_encontrado # profundidade completa! profundidade_atual += 1 # tenta uma profundidade a mais except TimeoutError: pass # retorna melhor_movimento da última profundidade COMPLETA return melhor_movimento def _verificar_tempo(self, tempo_inicio): """Lança TimeoutError se o limite de tempo foi ultrapassado""" tempo_decorrido = (time.time() - tempo_inicio) * 1000 if tempo_decorrido >= self.limite_tempo: raise TimeoutError()
Por que recomputar? A cada nova profundidade, o custo extra é pequeno — as buscas anteriores representam apenas 1/(b-1) do trabalho da última. Para b=30 e d=5, recomputar d=1..4 acrescenta apenas ~3% de overhead.

class IsolationAgent: """Agente completo — todos os componentes integrados""" def __init__(self): self.heuristic = HeuristicAgent() self.time_limit = 150 # ms por jogada def choose_action(self, game): """Pipeline completo: ID → Alpha-Beta → Heurística""" start = time.time() best_move = game.get_legal_actions()[0] # fallback seguro depth = 1 try: while True: self._check_time(start) # lança TimeoutError se expirou move = self._alpha_beta_root( # Alpha-Beta nesta profundidade game, depth, start ) best_move = move # salva — esta profundidade está completa depth += 1 except TimeoutError: pass # retorna best_move da última profundidade completa return best_move def _eval_leaf(self, state): """Ponto de encontro: Alpha-Beta chama Heurística nas folhas""" return self.heuristic.score(state)
Separação de responsabilidades: o Aprofundamento Iterativo controla o tempo, o Alfa-Beta controla a busca, e a Heurística controla a avaliação. Cada camada pode ser melhorada independentemente sem quebrar as outras.
